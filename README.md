# 🪶 Xero Client

> *A lightweight, privacy-first Minecraft client for the modern player.*

---

## Project Status

**Status:** Planned  
**Expected Release:** After Deepslate Client

Xero Client is currently in the planning phase. Development will commence following the release of Deepslate Client.

---

## Project Overview

Xero Client is a Fabric-based Minecraft client designed as a direct alternative to **Feather Client**. It offers the sleek, modern interface and lightweight performance that players expect, while eliminating the corporate data collection and advertising present in existing solutions.

The client is being developed as part of the **SunEclipseMC** initiative, with a focus on privacy, open-source transparency, and community governance.

---

## Inspiration

Xero Client is inspired by the design philosophy and user experience of Feather Client:

- **Feather Client** – Modern user interface, lightweight design, and seamless user experience.

**Built differently:**

Feather Client, like its corporate counterparts, operates under a closed-source, data-driven business model. Xero Client is built to offer a similar refined experience—without the tracking, data brokers, or corporate oversight.

## Planned Features

- **Lightweight Performance:** Minimal resource usage and fast load times.
- **Modern User Interface:** Clean, intuitive, and visually polished design.
- **Seamless Experience:** Smooth navigation and user-friendly controls.
- **Customizable HUD:** Configurable interface elements.
- **Mod Compatibility:** Support for Fabric-based mods.
- **Security:** No telemetry, no analytics, no data collection.
- **Cross-Platform:** Support for Windows, macOS, and Linux.
